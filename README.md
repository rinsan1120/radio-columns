# radio-columns

だいふくが生成するコラム音声の「作りだめ」置き場です。

## 置き方

- 音声（mp3）と台本（出典リンク付きテキスト）は、生成した日ごとに **Releases** へ配置します（タグは生成日、例：`2026-11-08`）
- リポジトリ本体へ音声ファイルはコミットしません（Gitの履歴が膨らみ続けるため）
- 在庫の台帳（生成待ち／配置済み／持ち越し／消費済み）は、手元の「ニュース候補」ページで管理しています。このリポジトリは配布専用です

## 聞き方

Releases から聞きたい回の mp3 をダウンロードして再生してください。

## クレジット

- 音声：Muse（だいふく）の音声合成、および COEIROINK（つくよみちゃん／アメノちゃん）の音声を使用する場合があります
